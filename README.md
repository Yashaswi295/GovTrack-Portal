# 🏛️ GovTrack: Citizen Portal for Government Project Transparency

A web-based Grievance Management System enabling citizens to submit, 
track and resolve complaints through a transparent digital workflow.

---

## 🚀 Features
- 🔐 Secure multi-role authentication (User, Department, Admin)
- 🤖 NLP-based auto complaint classification & department assignment
- 📊 Real-time status tracking and complaint lifecycle management
- 📋 Admin dashboard with analytics and report generation
- 🛡️ SQL injection prevention with parameterized queries
- 📱 Responsive UI with Bootstrap

---

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Backend | Python, Flask |
| Database | MySQL |
| Frontend | HTML, CSS, JavaScript, Bootstrap |
| Auth | Flask Sessions, Werkzeug |
| AI/NLP | NLP-based Classification |

---

## 👥 User Roles
| Role | Access |
|------|--------|
| Citizen/User | Register, submit & track grievances |
| Department | View, respond & resolve assigned complaints |
| Admin | Manage users, departments & monitor system |

---

## ⚙️ Setup & Installation

1. Clone the repository
git clone https://github.com/Yashaswi295/GovTrack-Portal.git

2. Install dependencies
pip install flask mysql-connector-python werkzeug

3. Configure database
- Create MySQL database
- Run the provided SQL script

4. Add your .env file
OPENAI_API_KEY=your_key_here

5. Run the application
python app.py

6. Open in browser
http://localhost:5000
